対象: many-ai-usage 検討中 v0.1 · 2026-07-20

更新中スポンサー枠 モック

更新の待ち時間に限って、ポップアップの最下部へ小さなスポンサー枠を表示する案。広告であることを明記し、サービスカードや更新結果と混同させない。

画面リスト

ID画面名概要
S-01通常表示更新前・更新完了後。スポンサー枠は出さない。
S-02更新中読み込み状態の間だけ、明示ラベル付きのスポンサー枠を表示する。
S-03広告を閉じた状態この更新中はスポンサー枠を非表示にし、次回以降の設定選択肢を示す。

S-01 通常表示

many-ai-usage
Claude残り 62%
ChatGPT残り 40%
GitHub Copilot未設定

スポンサー枠は通常表示には出さない。更新中だけに限定する。

S-02 更新中

更新ボタンを押してから結果が戻るまでの状態。ここだけスポンサー枠を表示する。

見え方

many-ai-usage
3 サービスを更新しています…
Claude読み込み中
ChatGPT読み込み中
SPONSORED
[スポンサー名]
開発者向けの便利なサービスを紹介する短い説明。
詳しく見る

置く理由

待機中だけに出すので、残量を読む操作を邪魔しない。

SPONSORED を先頭に置き、サービスの残量カードと明確に分離する。

× で即座に閉じられる。クリックを強制しない。

避ける見せ方

更新結果のカードに見せかけない。

「残り時間」と偽装しない。

外部ページ上には表示しない。拡張ポップアップの中だけに置く。

S-03 広告を閉じた状態

many-ai-usage
3 サービスを更新しています…
Claude読み込み中
ChatGPT読み込み中
SPONSORED非表示
この更新中のスポンサー枠は閉じました。
設定から常に非表示にもできます。
